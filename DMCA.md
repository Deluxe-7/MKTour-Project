# DMCA Policy
Welcome to the Mario Kart Tour Preservation Project's takedown policy page. This page will describe how the project handles DMCA notices and how to submit them.

## GitHub Notice
This project is currently hosted on the platform GitHub, and we will respect all requests sent through GitHub's methods. While we ask for you (that is a copyright holder, or accused party) to work with us directly for handling DMCA, we also respect GitHub's authority and terms and conditions relating to the DMCA. For GitHub's stated policy on the DMCA, please see here:
- [GitHub's Takedown Policy](https://docs.github.com/en/site-policy/content-removal-policies/dmca-takedown-policy)
